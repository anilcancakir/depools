Depools.ai design preview

Four colour palettes and four font pairings, each rendered as the actual inventory screen rather than as swatches, because a palette only tells you the truth once it is carrying real content. Every value here is verified: Apple system colours cross-checked across three independent compilations, Turkish glyph coverage confirmed at codepoint level, contrast ratios computed live on this page.

Before you choose: one real conflict

Apple's own systemBlue #007AFF with white text measures 4.02:1. Our design:lint enforces 4.5:1 on every on-X/X pair, in both light and dark. So the raw Apple blue does not pass our own build gate.

This is not an Apple mistake. Apple leans on larger text sizes and its own font rendering, while WCAG AA for normal-size body text is stricter. It is a decision only you can make, so every palette below shows both: the raw Apple hue, and the darkened variant that clears 4.5:1. The audit table further down computes each one.

1. Font pairings

Same Turkish content in every pairing, at the real type scale from DESIGN.md. Look at three things: how the headline weight feels, whether the Turkish diacritics sit comfortably (Ğ ğ İ ı Ş ş are the ones that break), and whether the quantity column lines up.

2. Palettes, on the real screen

Light and dark side by side, because a token that works in one often fails in the other. Each screen uses tonal surface steps rather than shadows, concentric corner radii, and one chromatic accent with everything else neutral, which is what carries the Apple-first feel more than the hue choice does.

3. Contrast audit

Computed live with the WCAG relative-luminance formula, the same one design:lint uses. Rows marked ham Apple are the untouched Apple values and are shown faded because most of them fail; rows marked sevk edilen are the adjusted values the screens above actually render. The border / surface row is dekoratif and exempt: WCAG 1.4.11 applies to UI components and meaningful graphics, not to a hairline separator whose boundary is already carried by the surface step. Apple's own separator at 29% opacity would fail this row too.

4. Paste-ready tokens

The winning palette's block goes straight into DESIGN.md, then dart run bin/dispatcher.dart design:sync generates the Wind theme.

Turkish support caveat worth carrying into implementation: ı (U+0131) ships in the base latin subset but Ğ ğ İ Ş ş live in latin-ext (U+0100-02BA). Requesting only the latin subset silently breaks Turkish text.
